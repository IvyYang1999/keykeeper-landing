## Design Context

### Users
People starting to build with AI agents who need to obtain, store, and use provider API keys without pasting secret values into chats or project files. The provider wall helps them recognize a service and find its setup guide.

### Brand Personality
Clear, restrained, and trustworthy. Explain security boundaries plainly; avoid decorative UI that makes provider identity or interaction states harder to understand.

### Aesthetic Direction
Keep the site's existing compact, neutral, macOS-adjacent visual language. Provider tiles start as recognizable symbols and expand in place to reveal a consistent plain-text name. Prefer official assets only when their use is permitted; otherwise use a clearly generic symbol or text.

### Design Principles
- Preserve the 48px tile rhythm and let expansion push neighbouring tiles instead of covering them.
- Keep hover and keyboard-focus transitions equally legible and interruptible; respect reduced motion.
- Use one visual treatment for provider names rather than mixing oversized wordmarks and text.
- Verify both compact and expanded states on desktop and narrow screens before publishing.
