## 0.3.8 — 2026-11-26

- 安全修复：[GHSA-hfqh-j87q-cccx](https://github.com/IvyYang1999/KeyKeeper/security/advisories/GHSA-hfqh-j87q-cccx)（中危）。0.3.7 的迁移辅助程序可能把早期版本的数据暴露给本机其他程序。只影响 0.3.7。
- 从 0.3.7 之前的版本迁移，改由 App 内置的只读迁移服务完成。
- 复制完成后，KeyKeeper 列出还在的旧钥匙串条目名称，并可打开「钥匙串访问」。KeyKeeper 不会自己删除它们。
- 从 0.3.6 或更早版本升级的，先在当前 App 里核对需要的凭据和网站登录态，再到「设置 › 开发者 › 0.3.7 之前的旧副本」查看旧副本。同名备份、或确认不了是否已复制的条目，请保留；全新安装无需清理。

## 0.3.7 — 2026-11-10

- 可选 iCloud 同步，默认关闭：在同一 Apple 账号的多台 Mac 之间同步加密的密钥、名称、字段和备注。缺值记录会保留，不会覆盖另一台 Mac 上已有的值。每台 Mac 各自批准调用方；授权记录和网站登录态只留在本机。
- 新的受保护存储，使用新的 App 身份；全新安装有独立的本机准备流程。从旧公开版升级时，需要确认一次先复制的本机迁移——原数据留在原处，调用方要重新批准。
- 同步暂停后会自动恢复。修复启动时重试反而关闭同步，以及关闭同步后旧请求又把它打开的问题。
- 重做欢迎引导、添加与编辑、详情、设置、网站登录态、使用权限和访问记录页面。引导时可选 Codex 或 Claude Code；自动生成的 ID 和环境变量名与手填的名称分开显示，授权详情可以展开。
- 修复在 Git worktree 里构建时 CLI 显示 unknown 版本，以及设置页误报已是最新。改进中英文文案、窄分栏、输入框、过期提示和隐藏值预览。

## 0.3.6 — 2026-10-28

- 更新：运行时默认每 6 小时检查一次，在后台下载签名更新、退出时安装；一直不退出时，一天后会提醒。已保存的更新选择保持不变。设置项改名为「在后台下载更新」，关闭后仍会检查，但下载前会询问。
- `keykeeper run --env` 把字段精确映射到程序要的环境变量名；`--plan` 预览映射和本机是否有值，不读取密钥值，也不启动命令。命令失败时，`run` 会说明是否已经注入。
- Agent 首次使用指引更清楚，授权窗更简洁。
- 发布：更新源和安装包都校验签名，并与已发布的文件逐字节核对。发布中断后可以安全续发，不会覆盖不同的版本，网络故障也不再被当成「版本不存在」。

## 0.3.5 — 2026-09-16

- 许可证：App、CLI、核心库从 MIT 改为 FSL-1.1-MIT——源码公开、不可做竞品、每个版本发布两年后变回 MIT。SDK、skill、插件保持 MIT。
- `keykeeper import ./.env` 把项目导入成一条只注入凭据：批准变量名后，所有导入值进入钥匙串，不猜测哪些值可以公开。原文件保留，先核对跳过项并验证项目再自行删除。仅支持单行赋值，不执行变量/命令展开；格式不完整或多行值会整份拒绝。
- 服务商选择器按品牌分行，地区和套餐折在品牌下；113 个模板，每个一页文档。
- 随 App 提供 Codex 和 Claude Code 双插件，设置中有安装指引。
- 访问/变更记录分开，记录与调用方权限均可下钻；历史结果与当前批准状态分开显示。
- 修复批准状态刷新、展开授权窗后边角异常，以及已有网站登录态时 Chrome 导入入口丢失。

## 0.3.4 — 2026-09-15

- 授权记录从明文文件搬进 App 独占的钥匙串条目。「始终」只对被批准的程序有效；没签名的 App 按它运行的文件认；新安装默认强制后台审批。已有授权会各再问一次。
- 授权窗改版：Agent 的留言放正中，KeyKeeper 自己的结论，三个回答——仅这一次、这次运行期间、以后都不问。
- 请求带 `--reason`（没带的在窗口里橙字提示）；新建 key 要声明用途；规则会点名夸大的请求；可选的第二模型审查员给意见。
- 只注入的凭据：Agent 新建的 key 只交给 `keykeeper run`。
- 通过命令行写入的明文字段，人在 App 里确认后才注入。
- 剪贴板保存直接取当前内容，并显示遮罩预览和复制时间。
- 可以在 KeyKeeper 里登录网站；凭据可以记录过期日。
