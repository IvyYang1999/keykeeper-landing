## 0.3.5 — 2026-09-16

- 许可证：App、CLI、核心库从 MIT 改为 FSL-1.1-MIT——源码公开、不可做竞品、每个版本发布两年后变回 MIT。SDK、skill、插件保持 MIT。
- `keykeeper import ./.env` 把项目导入成一条只注入凭据：批准变量名后，所有导入值进入钥匙串，不猜测哪些值可以公开。原文件保留，先核对跳过项并验证项目再自行删除。仅支持单行赋值，不执行变量/命令展开；格式不完整或多行值会整份拒绝。
- 服务商选择器按品牌分行，地区和套餐折在品牌下；113 个模板，每个一页文档。
- 随 App 提供 Codex 和 Claude Code 双插件，设置中有安装指引。
- 访问/变更记录分开，记录与调用方权限均可下钻；历史结果与当前批准状态分开显示。
- 修复批准状态刷新、展开授权窗后边角异常，以及已有网站登录态时 Chrome 导入入口丢失。

## 0.3.4 — 2026-09-15

- 授权记录从明文文件搬进 App 独占的钥匙串条目。「始终」只对被批准的程序有效；没签名的 App 按它运行的文件认；新安装默认强制后台审批。已有授权会各再问一次。
- 授权窗改版：Agent 的留言放正中，KeyKeeper 自己的结论，三个回答——仅这一次、这次运行期间、以后都不问。
- 请求带 `--reason`（没带的在窗口里橙字提示）；新建 key 要声明用途；规则会点名夸大的请求；可选的第二模型审查员给意见。
- 只注入的凭据：Agent 新建的 key 只交给 `keykeeper run`。
- 通过命令行写入的明文字段，人在 App 里确认后才注入。
- 剪贴板保存直接取当前内容，并显示遮罩预览和复制时间。
- 可以在 KeyKeeper 里登录网站；凭据可以记录过期日。
