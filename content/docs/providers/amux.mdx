## What the agent does

```bash
keykeeper providers show amux
keykeeper save --provider amux --from-clipboard --create --purpose "what this task does"
keykeeper run -c amux -- <your command>
```

`--provider amux` fills in the credential id and the field. The environment
variable is the one Amux API's own tools read, so nothing has to be mapped.

## What KeyKeeper checks

- **Before writing:** the value must look like a Amux API key (can be viewed again in the console). A wrong paste is refused before anything is stored, and the agent is told why — without the value.
- **After saving:** Amux API offers no read-only endpoint KeyKeeper can use, so the first real call is the test.


## Endpoints

The key is a bearer token for these endpoints. `keykeeper run` sets only the variables above;
point your client at the base URL yourself.

- **OpenAI compatible** — `https://gateway.amux.ai/v1`
- **Anthropic Messages** — `https://gateway.amux.ai`
- **Gemini native** — `https://gateway.amux.ai`

## Rotation and expiry

官方未说明统一到期策略；完整 key 可在 keys 页面再次查看，不需要仅为找回值而轮换。 Rotate or revoke at [amux.ai](https://amux.ai/keys).
