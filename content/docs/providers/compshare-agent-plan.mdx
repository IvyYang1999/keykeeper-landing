## What the agent does

```bash
keykeeper providers show compshare-agent-plan
keykeeper save --provider compshare-agent-plan --from-clipboard --create --purpose "what this task does"
keykeeper run -c compshare-agent-plan -- <your command>
```

`--provider compshare-agent-plan` fills in the credential id and the field. The environment
variable is the one Compshare's own tools read, so nothing has to be mapped.

## What to choose

仅保存 Agent Plan 专用 key；官方明确要求从普通按量 API 切换时同时更换 Base URL 和 API Key。不要保存本地 ccx 代理的 PROXY_ACCESS_KEY。

<Callout type="info">
The agent is told the same thing. It opens the page for you and says what to pick; it never
logs in, passes 2FA or pays on your behalf.
</Callout>

## What KeyKeeper checks

- **Before writing:** the value must look like a Compshare · Agent Plan key (can be viewed again in the console). A wrong paste is refused before anything is stored, and the agent is told why — without the value.
- **After saving:** Compshare · Agent Plan offers no read-only endpoint KeyKeeper can use, so the first real call is the test.


## Endpoints

The key is a bearer token for these endpoints. `keykeeper run` sets only the variables above;
point your client at the base URL yourself.

- **OpenAI compatible** — `https://cp.compshare.cn/v1`
- **Anthropic Messages** — `https://cp.compshare.cn`

## Rotation and expiry

密钥随 Agent Plan 到期或配额耗尽而停止工作；实际到期日以账户套餐页为准。 Rotate or revoke at [console.compshare.cn](https://console.compshare.cn/light-gpu/model-manage).
