## Agent 做什么

```bash
keykeeper providers show alibaba-bailian-us
keykeeper save --provider alibaba-bailian-us --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c alibaba-bailian-us -- <你的命令>
```

`--provider alibaba-bailian-us` 会补上凭据 ID 和字段名。这些环境变量就是 阿里云百炼 自家工具读的那个，不需要任何映射。

## 只有你能做的

<Steps>
<Step>登录阿里云，选择 美国弗吉尼亚（us-east-1）与对应业务空间</Step>
<Step>在 API Key 管理中创建该地区的按量 key；不要复制 Coding / Token Plan key</Step>
<Step>配置同地区 endpoint；业务空间专属域名需从控制台确认 WorkspaceId</Step>
<Step>复制 key，然后在 KeyKeeper 的窗口里确认保存。</Step>
</Steps>

## 该选什么

不同地区的 key 不通用。优先独立业务空间、限制模型与 IP 的自定义权限。

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 阿里云百炼 · 按量 (美国弗吉尼亚) 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** 阿里云百炼 · 按量 (美国弗吉尼亚) 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 接入地址

这把 key 是下面这些地址的 bearer token。`keykeeper run` 只设置上面的环境变量，base URL 要你自己在客户端里指。

- **OpenAI**——`https://dashscope-us.aliyuncs.com/compatible-mode/v1`（us-east-1）
- **Anthropic**——`https://dashscope-us.aliyuncs.com/apps/anthropic`（us-east-1）
- **DashScope**——`https://dashscope-us.aliyuncs.com/api/v1`（us-east-1）
- **OpenAI · workspace (replace WorkspaceId)**——`https://{WorkspaceId}.us-east-1.maas.aliyuncs.com/compatible-mode/v1`（us-east-1）

## 轮换与过期

本模板管理持久 API Key，无固定有效期；不是最多 1800 秒的临时 key。仍可能被撤销。 在 [bailian.console.aliyun.com](https://bailian.console.aliyun.com/) 轮换或撤销。
