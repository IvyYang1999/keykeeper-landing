## What the agent does

```bash
keykeeper providers show rightcode-codex
keykeeper save --provider rightcode-codex --from-clipboard --create --purpose "what this task does"
keykeeper run -c rightcode-codex -- <your command>
```

`--provider rightcode-codex` fills in the credential id and the field. The environment
variable is the one RightCode · Codex's own tools read, so nothing has to be mapped.

## What KeyKeeper checks

- **Before writing:** the value must look like a RightCode · Codex key (can be viewed again in the console). A wrong paste is refused before anything is stored, and the agent is told why — without the value.
- **After saving:** RightCode · Codex offers no read-only endpoint KeyKeeper can use, so the first real call is the test.


## Endpoints

The key is a bearer token for these endpoints. `keykeeper run` sets only the variables above;
point your client at the base URL yourself.

- **OpenAI Responses** — `https://rightapi.ai/codex/v1`
