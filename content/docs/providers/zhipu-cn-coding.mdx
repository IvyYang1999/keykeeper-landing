## What the agent does

```bash
keykeeper providers show zhipu-cn-coding
keykeeper save --provider zhipu-cn-coding --from-clipboard --create --purpose "what this task does"
keykeeper run -c zhipu-cn-coding -- <your command>
```

`--provider zhipu-cn-coding` fills in the credential id and the field. The environment
variable is the one 智谱 · Z.AI's own tools read, so nothing has to be mapped.

## What to choose

Use only with officially supported coding tools and the dedicated https://open.bigmodel.cn/api/coding/paas/v4 endpoint (or https://open.bigmodel.cn/api/anthropic for Anthropic Messages). Team Coding Plan keys are not interchangeable with other platform API keys.

<Callout type="info">
The agent is told the same thing. It opens the page for you and says what to pick; it never
logs in, passes 2FA or pays on your behalf.
</Callout>

## What KeyKeeper checks

- **Before writing:** the value must look like a 智谱 · GLM Coding Plan (中国) key (can be viewed again in the console). A wrong paste is refused before anything is stored, and the agent is told why — without the value.
- **After saving:** 智谱 · GLM Coding Plan (中国) offers no read-only endpoint KeyKeeper can use, so the first real call is the test.


## Endpoints

The key is a bearer token for these endpoints. `keykeeper run` sets only the variables above;
point your client at the base URL yourself.

- **OpenAI Chat Completions** — `https://open.bigmodel.cn/api/coding/paas/v4` (China)
- **Anthropic Messages** — `https://open.bigmodel.cn/api/anthropic` (China)
- **OpenAI Responses** — `https://open.bigmodel.cn/api/v1` (China)

## Rotation and expiry

No universal expiry policy was confirmed for this credential type. Record the date shown by the provider, or leave it unknown. Rotate or revoke at [bigmodel.cn](https://bigmodel.cn/coding-plan/personal/overview).
