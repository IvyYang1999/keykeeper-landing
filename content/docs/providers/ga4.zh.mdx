## Agent 做什么

```bash
keykeeper providers show ga4
keykeeper save --provider ga4 --from-file /路径/google-application-credentials.json --create --purpose "这个任务是做什么的"
keykeeper run -c ga4 -- <你的命令>
```

`--provider ga4` 会补上凭据 ID 和字段名。这些环境变量就是 Google Analytics 4 自家工具读的那个，不需要任何映射。

## 该选什么

GA4 property role = Viewer for reporting. Do not grant Editor or Administrator. Grant access only to the properties the task reads.

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 Google Analytics 4 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** Google Analytics 4 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 轮换与过期

User-managed service-account keys usually remain valid until revoked, but organization policy can impose expiry. Record a date only when the console or policy shows one. 在 [console.cloud.google.com](https://console.cloud.google.com/iam-admin/serviceaccounts) 轮换或撤销。
