## What the agent does

```bash
keykeeper providers show alibaba-bailian-token-cn
keykeeper save --provider alibaba-bailian-token-cn --from-clipboard --create --purpose "what this task does"
keykeeper run -c alibaba-bailian-token-cn -- <your command>
```

`--provider alibaba-bailian-token-cn` fills in the credential id and the field. The environment
variable is the one 阿里云百炼's own tools read, so nothing has to be mapped.

## What to choose

A Token Plan key/base is isolated from both Coding Plan and pay-as-you-go. Mixing them can use the wrong quota or billing path.

<Callout type="info">
The agent is told the same thing. It opens the page for you and says what to pick; it never
logs in, passes 2FA or pays on your behalf.
</Callout>

## What KeyKeeper checks

- **Before writing:** the value must look like a 阿里云百炼 · Token Plan (中国) key (starts with `sk-sp-`, shown once when created). A wrong paste is refused before anything is stored, and the agent is told why — without the value.
- **After saving:** 阿里云百炼 · Token Plan (中国) offers no read-only endpoint KeyKeeper can use, so the first real call is the test.


## Endpoints

The key is a bearer token for these endpoints. `keykeeper run` sets only the variables above;
point your client at the base URL yourself.

- **OpenAI** — `https://token-plan.cn-beijing.maas.aliyuncs.com/compatible-mode/v1` (cn-beijing)
- **Anthropic** — `https://token-plan.cn-beijing.maas.aliyuncs.com/apps/anthropic` (cn-beijing)

## Rotation and expiry

No universal expiry policy was confirmed for this credential type. Record the date shown by the provider, or leave it unknown. Rotate or revoke at [bailian.console.aliyun.com](https://bailian.console.aliyun.com/).
