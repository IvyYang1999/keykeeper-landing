## What the agent does

```bash
keykeeper providers show crazyrouter
keykeeper save --provider crazyrouter --from-clipboard --create --purpose "what this task does"
keykeeper run -c crazyrouter -- <your command>
```

`--provider crazyrouter` fills in the credential id and the field. The environment
variable is the one CrazyRouter's own tools read, so nothing has to be mapped.

## What to choose

为每个 IDE、CLI 或 bot 创建不同 token；限制模型、IP 和日/月预算。模型 API 必须发往 API 域名，账户管理仍使用 crazyrouter.com。

## What KeyKeeper checks

- **Before writing:** the value must look like a CrazyRouter key (starts with `sk-`, can be viewed again in the console). A wrong paste is refused before anything is stored, and the agent is told why — without the value.
- **After saving:** CrazyRouter offers no read-only endpoint KeyKeeper can use, so the first real call is the test.


## Endpoints

The key is a bearer token for these endpoints. `keykeeper run` sets only the variables above;
point your client at the base URL yourself.

- **OpenAI compatible** — `https://api.crazyrouter.com/v1` (International)
- **Anthropic Messages** — `https://api.crazyrouter.com` (International)
- **OpenAI compatible** — `https://cn.crazyrouter.com/v1` (East Asia)
- **Anthropic Messages** — `https://cn.crazyrouter.com` (East Asia)
