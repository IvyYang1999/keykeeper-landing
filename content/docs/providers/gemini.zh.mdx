## Agent 做什么

```bash
keykeeper providers show gemini
keykeeper save --provider gemini --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c gemini -- <你的命令>
```

`--provider gemini` 会补上凭据 ID 和字段名。这些环境变量就是 Google Gemini 自家工具读的那个，不需要任何映射。

## 该选什么

创建只限 Gemini API 的 key（默认就是）。2026 年底起 Gemini 会拒绝不受限的 Standard key。

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 Google Gemini 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** KeyKeeper 自己发送 `GET https://generativelanguage.googleapis.com/v1beta/models`，key 放在 `x-goog-api-key` 请求头里（列出这把 key 能用的模型）。Agent 收到的是「接受」「拒绝」或「联系不上」——从不是值。


## 轮换与过期

key 不过期；删掉的 key 30 天内可以恢复。 在 [aistudio.google.com](https://aistudio.google.com/apikey) 轮换或撤销。
