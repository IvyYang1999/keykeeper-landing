## Agent 做什么

```bash
keykeeper providers show nvidia-ngc
keykeeper save --provider nvidia-ngc --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c nvidia-ngc -- <你的命令>
```

`--provider nvidia-ngc` 会补上凭据 ID 和字段名。这些环境变量就是 NVIDIA 自家工具读的那个，不需要任何映射。

## 该选什么

Personal Key 仅选择所需 services；机器工作负载优先使用 Service Key，并按实体与动作收窄 scope。

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 NVIDIA · NGC 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** NVIDIA · NGC 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 接入地址

这把 key 是下面这些地址的 bearer token。`keykeeper run` 只设置上面的环境变量，base URL 要你自己在客户端里指。

- **OCI/Docker Registry**——`https://nvcr.io`

## 轮换与过期

Personal Key 在创建时选择到期日期；Service Key 的统一到期合同未从本轮公开页面闭合。 在 [org.ngc.nvidia.com](https://org.ngc.nvidia.com/setup/api-keys) 轮换或撤销。
