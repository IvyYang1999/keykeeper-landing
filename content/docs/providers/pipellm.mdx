## What the agent does

```bash
keykeeper providers show pipellm
keykeeper save --provider pipellm --from-clipboard --create --purpose "what this task does"
keykeeper run -c pipellm -- <your command>
```

`--provider pipellm` fills in the credential id and the field. The environment
variable is the one PipeLLM's own tools read, so nothing has to be mapped.

## What KeyKeeper checks

- **Before writing:** the value must look like a PipeLLM key (can be viewed again in the console). A wrong paste is refused before anything is stored, and the agent is told why — without the value.
- **After saving:** PipeLLM offers no read-only endpoint KeyKeeper can use, so the first real call is the test.


## Endpoints

The key is a bearer token for these endpoints. `keykeeper run` sets only the variables above;
point your client at the base URL yourself.

- **Native public routes** — `https://api.pipellm.ai`
- **OpenAI converter** — `https://api.pipellm.ai/openai/v1`
- **Anthropic converter** — `https://api.pipellm.ai/anthropic`
- **Gemini converter** — `https://api.pipellm.ai/gemini`
