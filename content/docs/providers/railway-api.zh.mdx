## Agent 做什么

```bash
keykeeper providers show railway-api
keykeeper save --provider railway-api --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c railway-api -- <你的命令>
```

`--provider railway-api` 会补上凭据 ID 和字段名。这些环境变量就是 Railway 自家工具读的那个，不需要任何映射。

## 该选什么

Use this broader API token only for work that genuinely spans projects. For one environment use the separate Railway Project token.

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 Railway · Account API Token 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** Railway · Account API Token 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 轮换与过期

No universal expiry policy was confirmed for this credential type. Record the date shown by the provider, or leave it unknown. 在 [railway.com](https://railway.com/account/tokens) 轮换或撤销。
