## Agent 做什么

```bash
keykeeper providers show rightcode-codex
keykeeper save --provider rightcode-codex --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c rightcode-codex -- <你的命令>
```

`--provider rightcode-codex` 会补上凭据 ID 和字段名。这些环境变量就是 RightCode · Codex 自家工具读的那个，不需要任何映射。

## 该选什么

仅开放任务需要的模型；是否允许套餐耗尽后继续扣余额必须由用户明确选择。此模板只覆盖官方文档确认的 Codex endpoint。

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 RightCode · Codex 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** RightCode · Codex 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。
