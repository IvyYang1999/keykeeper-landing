## What the agent does

```bash
keykeeper providers show minimax
keykeeper save --provider minimax --from-clipboard --create --purpose "what this task does"
keykeeper run -c minimax -- <your command>
```

`--provider minimax` fills in the credential id and the field. The environment
variable is the one MiniMax's own tools read, so nothing has to be mapped.

## What to choose

Keep pay-as-you-go and Token Plan keys separate; use the plan-specific key only with its matching endpoint.

<Callout type="info">
The agent is told the same thing. It opens the page for you and says what to pick; it never
logs in, passes 2FA or pays on your behalf.
</Callout>

## What KeyKeeper checks

- **Before writing:** the value must look like a MiniMax · Pay-as-you-go (China) key (can be viewed again in the console). A wrong paste is refused before anything is stored, and the agent is told why — without the value.
- **After saving:** MiniMax · Pay-as-you-go (China) offers no read-only endpoint KeyKeeper can use, so the first real call is the test.


## Endpoints

The key is a bearer token for these endpoints. `keykeeper run` sets only the variables above;
point your client at the base URL yourself.

- **OpenAI** — `https://api.minimaxi.com/v1`
- **Anthropic** — `https://api.minimaxi.com/anthropic`

## Rotation and expiry

No universal expiry policy was confirmed for this credential type. Record the date shown by the provider, or leave it unknown. Rotate or revoke at [platform.minimaxi.com](https://platform.minimaxi.com/user-center/basic-information/interface-key).
