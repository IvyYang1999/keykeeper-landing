## Agent 做什么

```bash
keykeeper providers show app-store-connect
keykeeper save --provider app-store-connect --from-file /路径/private-key.p8 --create --purpose "这个任务是做什么的"
keykeeper run -c app-store-connect -- <你的命令>
```

`--provider app-store-connect` 会补上凭据 ID 和字段名。这些环境变量就是 App Store Connect 自家工具读的那个，不需要任何映射。

## 只有你能做的

<Steps>
<Step>Sign in to App Store Connect</Step>
<Step>An Account Holder or Admin chooses Team Keys and creates the key</Step>
<Step>Choose the least privileged role the task needs</Step>
<Step>Download the .p8 file immediately; it is shown once</Step>
<Step>复制 key，然后在 KeyKeeper 的窗口里确认保存。</Step>
</Steps>

## 该选什么

Prefer a team key with the narrowest App Store Connect role that can perform the task. Use an individual key only for app and user endpoints; Apple does not allow individual keys for notarytool.

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 App Store Connect · Team API Key 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** App Store Connect · Team API Key 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 轮换与过期

Keys do not expire automatically; revoke them on the Integrations page. 在 [appstoreconnect.apple.com](https://appstoreconnect.apple.com/access/integrations/api) 轮换或撤销。
