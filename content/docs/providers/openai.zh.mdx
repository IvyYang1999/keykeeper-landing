## Agent 做什么

```bash
keykeeper providers show openai
keykeeper save --provider openai --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c openai -- <你的命令>
```

`--provider openai` 会补上凭据 ID 和字段名。这个字段的环境变量就是 OpenAI 自家工具读的那个，不需要任何映射。

## 该选什么

创建 Restricted（受限）权限的 key：只勾任务需要的能力（通常是 Model capabilities: Write），不要选 All。

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 OpenAI 的 key（以 `sk-` 开头，至少 40 个字符）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** KeyKeeper 自己发送 `GET https://api.openai.com/v1/models`，key 放在 `Authorization` 请求头里（列出这把 key 能用的模型）。Agent 收到的是「接受」「拒绝」或「联系不上」——从不是值。

## 轮换与过期

key 不会过期，除非撤销。 在 [platform.openai.com](https://platform.openai.com/api-keys) 轮换或撤销。
