## Agent 做什么

```bash
keykeeper providers show neon-org
keykeeper save --provider neon-org --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c neon-org -- <你的命令>
```

`--provider neon-org` 会补上凭据 ID 和字段名。这些环境变量就是 Neon 自家工具读的那个，不需要任何映射。

## 该选什么

Prefer a project-scoped organization key for an agent so it cannot see unrelated projects or create more keys.

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 Neon · Organization or project API Key 的 key（以 `napi_` 开头）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** KeyKeeper 自己发送 `GET https://console.neon.tech/api/v2/projects`，key 放在 `Authorization` 请求头里（lists projects visible to this organization key）。Agent 收到的是「接受」「拒绝」或「联系不上」——从不是值。


## 轮换与过期

No universal expiry policy was confirmed for this credential type. Record the date shown by the provider, or leave it unknown. 在 [console.neon.tech](https://console.neon.tech/app) 轮换或撤销。
