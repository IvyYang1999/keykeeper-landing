## Agent 做什么

```bash
keykeeper providers show cloudflare-account
keykeeper save --provider cloudflare-account --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c cloudflare-account -- <你的命令>
```

`--provider cloudflare-account` 会补上凭据 ID 和字段名。这些环境变量就是 Cloudflare 自家工具读的那个，不需要任何映射。

## 只有你能做的

<Steps>
<Step>Sign in to Cloudflare</Step>
<Step>Open the target account → Manage Account → Account API Tokens</Step>
<Step>Create a least-privilege account-owned token and record the Account ID</Step>
<Step>复制 key，然后在 KeyKeeper 的窗口里确认保存。</Step>
</Steps>

## 该选什么

Use an account-owned token only for unattended account automation. Limit permissions/resources and set a TTL; it is distinct from a user token.

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 Cloudflare · Account API Token 的 key（以 `cfat_` 开头）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** Cloudflare · Account API Token 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 轮换与过期

No universal expiry policy was confirmed for this credential type. Record the date shown by the provider, or leave it unknown. 在 [dash.cloudflare.com](https://dash.cloudflare.com/) 轮换或撤销。
