## Agent 做什么

```bash
keykeeper providers show zhipu-cn
keykeeper save --provider zhipu-cn --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c zhipu-cn -- <你的命令>
```

`--provider zhipu-cn` 会补上凭据 ID 和字段名。这些环境变量就是 智谱 · Z.AI 自家工具读的那个，不需要任何映射。

## 该选什么

中国通用 API 使用 https://open.bigmodel.cn/api/paas/v4，按开放平台合同计费。Coding Plan 使用专用 endpoint 和套餐授权，不能按通用 API 路径假定扣套餐额度。每个项目单独建 key，保留独立撤销能力。

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 智谱 · 开放平台 (中国) 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** 智谱 · 开放平台 (中国) 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。
