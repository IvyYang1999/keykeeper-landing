## Agent 做什么

```bash
keykeeper providers show xiaomi-mimo-token-plan-eu
keykeeper save --provider xiaomi-mimo-token-plan-eu --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c xiaomi-mimo-token-plan-eu -- <你的命令>
```

`--provider xiaomi-mimo-token-plan-eu` 会补上凭据 ID 和字段名。这些环境变量就是 Xiaomi MiMo 自家工具读的那个，不需要任何映射。

## 该选什么

仅用于 欧洲集群的 Token Plan；不能与按量 key 或其他集群 Base URL 混用。

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 Xiaomi MiMo · Token Plan (Europe) 的 key（以 `tp-` 开头）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** Xiaomi MiMo · Token Plan (Europe) 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 接入地址

这把 key 是下面这些地址的 bearer token。`keykeeper run` 只设置上面的环境变量，base URL 要你自己在客户端里指。

- **OpenAI compatible**——`https://token-plan-ams.xiaomimimo.com/v1`（欧洲）
- **Anthropic compatible**——`https://token-plan-ams.xiaomimimo.com/anthropic`（欧洲）

## 轮换与过期

仅在所订阅 Token Plan 套餐的有效期内可用；到期后需续订。 在 [platform.xiaomimimo.com](https://platform.xiaomimimo.com/) 轮换或撤销。
