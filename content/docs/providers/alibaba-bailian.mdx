## What the agent does

```bash
keykeeper providers show alibaba-bailian
keykeeper save --provider alibaba-bailian --from-clipboard --create --purpose "what this task does"
keykeeper run -c alibaba-bailian -- <your command>
```

`--provider alibaba-bailian` fills in the credential id and the field. The environment
variable is the one 阿里云百炼's own tools read, so nothing has to be mapped.

## What to choose

Use a non-default workspace and Custom permission limited to the needed models and IP ranges. Keys and endpoints are region-specific.

## What KeyKeeper checks

- **Before writing:** the value must look like a 阿里云百炼 · 按量 (北京) key (whether it can be viewed again is unconfirmed). A wrong paste is refused before anything is stored, and the agent is told why — without the value.
- **After saving:** 阿里云百炼 · 按量 (北京) offers no read-only endpoint KeyKeeper can use, so the first real call is the test.


## Endpoints

The key is a bearer token for these endpoints. `keykeeper run` sets only the variables above;
point your client at the base URL yourself.

- **OpenAI** — `https://dashscope.aliyuncs.com/compatible-mode/v1` (cn-beijing)
- **Anthropic** — `https://dashscope.aliyuncs.com/apps/anthropic` (cn-beijing)
- **DashScope** — `https://dashscope.aliyuncs.com/api/v1` (cn-beijing)
- **OpenAI · workspace (replace WorkspaceId)** — `https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1` (cn-beijing)

## Rotation and expiry

No universal expiry policy was confirmed for this credential type. Record the date shown by the provider, or leave it unknown. Rotate or revoke at [bailian.console.aliyun.com](https://bailian.console.aliyun.com/?tab=model#/api-key).
