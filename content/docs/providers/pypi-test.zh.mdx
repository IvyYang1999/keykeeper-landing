## Agent 做什么

```bash
keykeeper providers show pypi-test
keykeeper save --provider pypi-test --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c pypi-test -- <你的命令>
```

`--provider pypi-test` 会补上凭据 ID 和字段名。这些环境变量就是 PyPI 自家工具读的那个，不需要任何映射。

## 该选什么

TestPyPI accounts and tokens are separate from production PyPI. Prefer a project-scoped token.

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 TestPyPI · API token 的 key（以 `pypi-` 开头，至少 90 个字符）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** TestPyPI · API token 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 轮换与过期

No universal expiry policy was confirmed for this credential type. Record the date shown by the provider, or leave it unknown. 在 [test.pypi.org](https://test.pypi.org/manage/account/token/) 轮换或撤销。
