## What the agent does

```bash
keykeeper providers show volcengine-ark
keykeeper save --provider volcengine-ark --from-clipboard --create --purpose "what this task does"
keykeeper run -c volcengine-ark -- <your command>
```

`--provider volcengine-ark` fills in the credential id and the field. The environment
variable is the one 火山方舟's own tools read, so nothing has to be mapped.

## What to choose

Use a dedicated key for this project and the matching regional Ark endpoint; avoid sharing an account-wide key across products.

<Callout type="info">
The agent is told the same thing. It opens the page for you and says what to pick; it never
logs in, passes 2FA or pays on your behalf.
</Callout>
