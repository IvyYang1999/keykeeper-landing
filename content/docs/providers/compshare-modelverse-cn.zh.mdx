## Agent 做什么

```bash
keykeeper providers show compshare-modelverse-cn
keykeeper save --provider compshare-modelverse-cn --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c compshare-modelverse-cn -- <你的命令>
```

`--provider compshare-modelverse-cn` 会补上凭据 ID 和字段名。这些环境变量就是 Compshare 自家工具读的那个，不需要任何映射。

## 该选什么

普通 ModelVerse 按量密钥；不要当作 Agent Plan 密钥。按项目拆分密钥并设置可承受的使用边界。

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 Compshare · ModelVerse (China) 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** Compshare · ModelVerse (China) 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 接入地址

这把 key 是下面这些地址的 bearer token。`keykeeper run` 只设置上面的环境变量，base URL 要你自己在客户端里指。

- **Anthropic Messages**——`https://api.modelverse.cn`（China）
