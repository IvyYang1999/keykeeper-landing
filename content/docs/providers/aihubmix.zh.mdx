## Agent 做什么

```bash
keykeeper providers show aihubmix
keykeeper save --provider aihubmix --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c aihubmix -- <你的命令>
```

`--provider aihubmix` 会补上凭据 ID 和字段名。这些环境变量就是 AIHubMix 自家工具读的那个，不需要任何映射。

## 该选什么

为每个项目创建独立 key，并按创建页面的有效期和使用限制收窄风险。备用域名只在主域名访问异常时使用。

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 AIHubMix 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** AIHubMix 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 接入地址

这把 key 是下面这些地址的 bearer token。`keykeeper run` 只设置上面的环境变量，base URL 要你自己在客户端里指。

- **OpenAI compatible**——`https://aihubmix.com/v1`（Primary）
- **OpenAI compatible**——`https://api.inferera.com/v1`（Official backup）

## 轮换与过期

官方要求留意每个 key 的 validity period；具体日期以创建页面显示为准。 在 [aihubmix.com](https://aihubmix.com/token) 轮换或撤销。
