## What the agent does

```bash
keykeeper providers show alibaba-bailian-hk
keykeeper save --provider alibaba-bailian-hk --from-clipboard --create --purpose "what this task does"
keykeeper run -c alibaba-bailian-hk -- <your command>
```

`--provider alibaba-bailian-hk` fills in the credential id and the field. The environment
variable is the one 阿里云百炼's own tools read, so nothing has to be mapped.

## What to choose

不同地区的 key 不通用。优先独立业务空间、限制模型与 IP 的自定义权限。

## What KeyKeeper checks

- **Before writing:** the value must look like a 阿里云百炼 · 按量 (中国香港) key (can be viewed again in the console). A wrong paste is refused before anything is stored, and the agent is told why — without the value.
- **After saving:** 阿里云百炼 · 按量 (中国香港) offers no read-only endpoint KeyKeeper can use, so the first real call is the test.


## Endpoints

The key is a bearer token for these endpoints. `keykeeper run` sets only the variables above;
point your client at the base URL yourself.

- **OpenAI** — `https://cn-hongkong.dashscope.aliyuncs.com/compatible-mode/v1` (cn-hongkong)
- **Anthropic** — `https://cn-hongkong.dashscope.aliyuncs.com/apps/anthropic` (cn-hongkong)
- **DashScope** — `https://cn-hongkong.dashscope.aliyuncs.com/api/v1` (cn-hongkong)
- **OpenAI · workspace (replace WorkspaceId)** — `https://{WorkspaceId}.cn-hongkong.maas.aliyuncs.com/compatible-mode/v1` (cn-hongkong)

## Rotation and expiry

本模板管理持久 API Key，无固定有效期；不是最多 1800 秒的临时 key。仍可能被撤销。 Rotate or revoke at [bailian.console.aliyun.com](https://bailian.console.aliyun.com/).
