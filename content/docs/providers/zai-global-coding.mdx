## What the agent does

```bash
keykeeper providers show zai-global-coding
keykeeper save --provider zai-global-coding --from-clipboard --create --purpose "what this task does"
keykeeper run -c zai-global-coding -- <your command>
```

`--provider zai-global-coding` fills in the credential id and the field. The environment
variable is the one 智谱 · Z.AI's own tools read, so nothing has to be mapped.

## What to choose

仅用于允许的 coding 场景：OpenAI 协议 https://api.z.ai/api/coding/paas/v4，Anthropic 协议 https://api.z.ai/api/anthropic。团队 key 与其他平台 key not interchangeable；不把团队规则推断为个人 key 有独立前缀或长度。

<Callout type="info">
The agent is told the same thing. It opens the page for you and says what to pick; it never

</Callout>

## What KeyKeeper checks

- **Before writing:** the value must look like a Z.AI · GLM Coding Plan (Global) key (can be viewed again in the console). A wrong paste is refused before anything is stored, and the agent is told why — without the value.
- **After saving:** Z.AI · GLM Coding Plan (Global) offers no read-only endpoint KeyKeeper can use, so the first real call is the test.


## Endpoints

The key is a bearer token for these endpoints. `keykeeper run` sets only the variables above;
point your client at the base URL yourself.

- **OpenAI Chat Completions** — `https://api.z.ai/api/coding/paas/v4` (Global)
- **Anthropic Messages** — `https://api.z.ai/api/anthropic` (Global)
- **OpenAI Responses** — `https://api.z.ai/api/v1` (Global)

## Rotation and expiry

No universal expiry policy was confirmed for this credential type. Record the date shown by the provider, or leave it unknown. Rotate or revoke at [z.ai](https://z.ai/manage-apikey/apikey-list).
