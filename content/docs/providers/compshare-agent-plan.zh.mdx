## Agent 做什么

```bash
keykeeper providers show compshare-agent-plan
keykeeper save --provider compshare-agent-plan --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c compshare-agent-plan -- <你的命令>
```

`--provider compshare-agent-plan` 会补上凭据 ID 和字段名。这些环境变量就是 Compshare 自家工具读的那个，不需要任何映射。

## 该选什么

仅保存 Agent Plan 专用 key；官方明确要求从普通按量 API 切换时同时更换 Base URL 和 API Key。不要保存本地 ccx 代理的 PROXY_ACCESS_KEY。

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 Compshare · Agent Plan 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** Compshare · Agent Plan 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 接入地址

这把 key 是下面这些地址的 bearer token。`keykeeper run` 只设置上面的环境变量，base URL 要你自己在客户端里指。

- **OpenAI compatible**——`https://cp.compshare.cn/v1`
- **Anthropic Messages**——`https://cp.compshare.cn`

## 轮换与过期

密钥随 Agent Plan 到期或配额耗尽而停止工作；实际到期日以账户套餐页为准。 在 [console.compshare.cn](https://console.compshare.cn/light-gpu/model-manage) 轮换或撤销。
