## Agent 做什么

```bash
keykeeper providers show siliconflow
keykeeper save --provider siliconflow --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c siliconflow -- <你的命令>
```

`--provider siliconflow` 会补上凭据 ID 和字段名。这些环境变量就是 SiliconFlow 硅基流动 自家工具读的那个，不需要任何映射。

## 该选什么

key 没有权限范围：一把 key 就是整个账号。每个项目建一把，方便单独删除。

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 SiliconFlow · China (硅基流动) 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** KeyKeeper 自己发送 `GET https://api.siliconflow.cn/v1/models`，key 放在 `Authorization` 请求头里（列出这把 key 能用的模型）。Agent 收到的是「接受」「拒绝」或「联系不上」——从不是值。


## 接入地址

这把 key 是下面这些地址的 bearer token。`keykeeper run` 只设置上面的环境变量，base URL 要你自己在客户端里指。

- **OpenAI**——`https://api.siliconflow.cn/v1`

## 轮换与过期

没有过期设置；轮换就是删掉重建。 在 [cloud.siliconflow.cn](https://cloud.siliconflow.cn/account/ak) 轮换或撤销。
