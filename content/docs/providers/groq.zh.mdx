## Agent 做什么

```bash
keykeeper providers show groq
keykeeper save --provider groq --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c groq -- <你的命令>
```

`--provider groq` 会补上凭据 ID 和字段名。这些环境变量就是 Groq 自家工具读的那个，不需要任何映射。

## 该选什么

Create the key inside a project dedicated to this workload; project limits are the isolation boundary.

Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 Groq 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** KeyKeeper 自己发送 `GET https://api.groq.com/openai/v1/models`，key 放在 `Authorization` 请求头里（lists available models）。Agent 收到的是「接受」「拒绝」或「联系不上」——从不是值。
