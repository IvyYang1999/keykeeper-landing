## What the agent does

```bash
keykeeper providers show feishu
keykeeper save --provider feishu --from-clipboard --create --purpose "what this task does"
keykeeper run -c feishu -- <your command>
```

`--provider feishu` fills in the credential id and the fields. The environment
variables are the ones Feishu / Lark's own tools read, so nothing has to be mapped.

## What to choose

Use a custom app with only the exact API permissions and smallest data scope needed. Keep App ID as public metadata and App Secret as the only secret field.

<Callout type="info">
The agent is told the same thing. It opens the page for you and says what to pick; it never
logs in, passes 2FA or pays on your behalf.
</Callout>

## What KeyKeeper checks

- **Before writing:** the value must look like a Feishu 飞书 (中国) key (can be viewed again in the console). A wrong paste is refused before anything is stored, and the agent is told why — without the value.
- **After saving:** Feishu 飞书 (中国) offers no read-only endpoint KeyKeeper can use, so the first real call is the test.


## Rotation and expiry

The App Secret remains valid until reset. Rotate or revoke at [open.feishu.cn](https://open.feishu.cn/app).
