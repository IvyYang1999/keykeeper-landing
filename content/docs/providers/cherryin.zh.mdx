## Agent 做什么

```bash
keykeeper providers show cherryin
keykeeper save --provider cherryin --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c cherryin -- <你的命令>
```

`--provider cherryin` 会补上凭据 ID 和字段名。这些环境变量就是 CherryIN 自家工具读的那个，不需要任何映射。

## 该选什么

日常通用调用使用 default 组的独立 token；折扣/促销组另建 token，禁止把组别不同的 key 当作可互换。为 key 设置用户可承受的额度。

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 CherryIN 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** CherryIN 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 接入地址

这把 key 是下面这些地址的 bearer token。`keykeeper run` 只设置上面的环境变量，base URL 要你自己在客户端里指。

- **OpenAI compatible**——`https://open.cherryin.net/v1`
- **Anthropic Messages**——`https://open.cherryin.net`
