## What the agent does

```bash
keykeeper providers show dmxapi-cn
keykeeper save --provider dmxapi-cn --from-clipboard --create --purpose "what this task does"
keykeeper run -c dmxapi-cn -- <your command>
```

`--provider dmxapi-cn` fills in the credential id and the field. The environment
variable is the one DMXAPI's own tools read, so nothing has to be mapped.

## What to choose

令牌与站点域名必须配套，禁止跨国内站、国际站和 SSVIP 混用。限制到任务需要的模型、IP、速率和有效期。

<Callout type="info">
The agent is told the same thing. It opens the page for you and says what to pick; it never
logs in, passes 2FA or pays on your behalf.
</Callout>

## What KeyKeeper checks

- **Before writing:** the value must look like a DMXAPI · 国内站 key (can be viewed again in the console). A wrong paste is refused before anything is stored, and the agent is told why — without the value.
- **After saving:** DMXAPI · 国内站 offers no read-only endpoint KeyKeeper can use, so the first real call is the test.


## Endpoints

The key is a bearer token for these endpoints. `keykeeper run` sets only the variables above;
point your client at the base URL yourself.

- **OpenAI compatible** — `https://www.dmxapi.cn/v1` (China · CNY discounted)
- **Anthropic Messages** — `https://www.dmxapi.cn` (China · CNY discounted)

## Rotation and expiry

创建时可设置到期时间；官方默认永久有效。以该令牌在创建页面选择的实际设置为准。 Rotate or revoke at [www.dmxapi.cn](https://www.dmxapi.cn).
