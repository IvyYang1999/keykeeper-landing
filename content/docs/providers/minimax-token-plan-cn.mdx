## What the agent does

```bash
keykeeper providers show minimax-token-plan-cn
keykeeper save --provider minimax-token-plan-cn --from-clipboard --create --purpose "what this task does"
keykeeper run -c minimax-token-plan-cn -- <your command>
```

`--provider minimax-token-plan-cn` fills in the credential id and the field. The environment
variable is the one MiniMax's own tools read, so nothing has to be mapped.

## What to choose

This subscription key is separate from pay-as-you-go. Use it only with the China Token Plan configuration.

<Callout type="info">
The agent is told the same thing. It opens the page for you and says what to pick; it never

</Callout>

## What KeyKeeper checks

- **Before writing:** the value must look like a MiniMax · Token Plan (China) key (starts with `sk-cp-`, shown once when created). A wrong paste is refused before anything is stored, and the agent is told why — without the value.
- **After saving:** MiniMax · Token Plan (China) offers no read-only endpoint KeyKeeper can use, so the first real call is the test.


## Endpoints

The key is a bearer token for these endpoints. `keykeeper run` sets only the variables above;
point your client at the base URL yourself.

- **OpenAI** — `https://api.minimaxi.com/v1`
- **Anthropic** — `https://api.minimaxi.com/anthropic`

## Rotation and expiry

No universal expiry policy was confirmed for this credential type. Record the date shown by the provider, or leave it unknown. Rotate or revoke at [platform.minimaxi.com](https://platform.minimaxi.com/subscribe/token-plan).
