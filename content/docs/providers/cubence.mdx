## What the agent does

```bash
keykeeper providers show cubence
keykeeper save --provider cubence --from-clipboard --create --purpose "what this task does"
keykeeper run -c cubence -- <your command>
```

`--provider cubence` fills in the credential id and the field. The environment
variable is the one Cubence's own tools read, so nothing has to be mapped.

## What KeyKeeper checks

- **Before writing:** the value must look like a Cubence key (can be viewed again in the console). A wrong paste is refused before anything is stored, and the agent is told why — without the value.
- **After saving:** Cubence offers no read-only endpoint KeyKeeper can use, so the first real call is the test.


## Endpoints

The key is a bearer token for these endpoints. `keykeeper run` sets only the variables above;
point your client at the base URL yourself.

- **OpenAI compatible** — `https://api.cubence.com/v1`
- **Anthropic Messages** — `https://api.cubence.com`
