## Agent 做什么

```bash
keykeeper providers show nvidia-api-catalog
keykeeper save --provider nvidia-api-catalog --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c nvidia-api-catalog -- <你的命令>
```

`--provider nvidia-api-catalog` 会补上凭据 ID 和字段名。这些环境变量就是 NVIDIA 自家工具读的那个，不需要任何映射。

## 该选什么

用于 NVIDIA 托管 NIM/API Catalog 推理；不要以 NGC personal/service key 替代。公开页面未确认统一的 key 权限粒度，也未保证 key 必定只显示一次。

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 NVIDIA · API Catalog 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** NVIDIA · API Catalog 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 接入地址

这把 key 是下面这些地址的 bearer token。`keykeeper run` 只设置上面的环境变量，base URL 要你自己在客户端里指。

- **OpenAI compatible hosted NIM**——`https://integrate.api.nvidia.com/v1`
