## Agent 做什么

```bash
keykeeper providers show alibaba-bailian
keykeeper save --provider alibaba-bailian --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c alibaba-bailian -- <你的命令>
```

`--provider alibaba-bailian` 会补上凭据 ID 和字段名。这些环境变量就是 阿里云百炼 自家工具读的那个，不需要任何映射。

## 该选什么

Use a non-default workspace and Custom permission limited to the needed models and IP ranges. Keys and endpoints are region-specific.

Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 阿里云百炼 · 按量 (北京) 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** 阿里云百炼 · 按量 (北京) 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 接入地址

这把 key 是下面这些地址的 bearer token。`keykeeper run` 只设置上面的环境变量，base URL 要你自己在客户端里指。

- **OpenAI**——`https://dashscope.aliyuncs.com/compatible-mode/v1`（cn-beijing）
- **Anthropic**——`https://dashscope.aliyuncs.com/apps/anthropic`（cn-beijing）
- **DashScope**——`https://dashscope.aliyuncs.com/api/v1`（cn-beijing）
- **OpenAI · workspace (replace WorkspaceId)**——`https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`（cn-beijing）
