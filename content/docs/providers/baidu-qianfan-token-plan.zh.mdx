## Agent 做什么

```bash
keykeeper providers show baidu-qianfan-token-plan
keykeeper save --provider baidu-qianfan-token-plan --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c baidu-qianfan-token-plan -- <你的命令>
```

`--provider baidu-qianfan-token-plan` 会补上凭据 ID 和字段名。这些环境变量就是 百度千帆 自家工具读的那个，不需要任何映射。

## 该选什么

Token 福利包使用千帆通用认证；不要把它与有独立 key 和独立路径的 Coding Plan 混用。

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 百度千帆 · Token 福利包 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** 百度千帆 · Token 福利包 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 接入地址

这把 key 是下面这些地址的 bearer token。`keykeeper run` 只设置上面的环境变量，base URL 要你自己在客户端里指。

- **OpenAI compatible**——`https://qianfan.baidubce.com/v2`
- **Anthropic compatible**——`https://qianfan.baidubce.com/anthropic`

## 轮换与过期

当前 Token 福利包文档列出的套餐有效期为 1 个月；API Key 本身是否随套餐到期未单独确认。 在 [console.bce.baidu.com](https://console.bce.baidu.com/iam/) 轮换或撤销。
