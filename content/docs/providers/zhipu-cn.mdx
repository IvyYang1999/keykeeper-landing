## What the agent does

```bash
keykeeper providers show zhipu-cn
keykeeper save --provider zhipu-cn --from-clipboard --create --purpose "what this task does"
keykeeper run -c zhipu-cn -- <your command>
```

`--provider zhipu-cn` fills in the credential id and the field. The environment
variable is the one 智谱 · Z.AI's own tools read, so nothing has to be mapped.

## What KeyKeeper checks

- **Before writing:** the value must look like a 智谱 · 开放平台 (中国) key (whether it can be viewed again is unconfirmed). A wrong paste is refused before anything is stored, and the agent is told why — without the value.
- **After saving:** 智谱 · 开放平台 (中国) offers no read-only endpoint KeyKeeper can use, so the first real call is the test.


## Endpoints

The key is a bearer token for these endpoints. `keykeeper run` sets only the variables above;
point your client at the base URL yourself.

- **OpenAI Chat Completions** — `https://open.bigmodel.cn/api/paas/v4` (China)

## Rotation and expiry

No universal expiry policy was confirmed for this credential type. Record the date shown by the provider, or leave it unknown. Rotate or revoke at [bigmodel.cn](https://bigmodel.cn/usercenter/proj-mgmt/apikeys).
