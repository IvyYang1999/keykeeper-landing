## What the agent does

```bash
keykeeper providers show baidu-qianfan-global
keykeeper save --provider baidu-qianfan-global --from-clipboard --create --purpose "what this task does"
keykeeper run -c baidu-qianfan-global -- <your command>
```

`--provider baidu-qianfan-global` fills in the credential id and the fields. The environment
variables are the ones 百度千帆's own tools read, so nothing has to be mapped.

## What KeyKeeper checks

- **Before writing:** the value must look like a 百度千帆 · 国际站 (Baidu AI Cloud Qianfan) key (can be viewed again in the console). A wrong paste is refused before anything is stored, and the agent is told why — without the value.
- **After saving:** 百度千帆 · 国际站 (Baidu AI Cloud Qianfan) offers no read-only endpoint KeyKeeper can use, so the first real call is the test.


## Endpoints
