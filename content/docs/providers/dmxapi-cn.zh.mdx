## Agent 做什么

```bash
keykeeper providers show dmxapi-cn
keykeeper save --provider dmxapi-cn --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c dmxapi-cn -- <你的命令>
```

`--provider dmxapi-cn` 会补上凭据 ID 和字段名。这些环境变量就是 DMXAPI 自家工具读的那个，不需要任何映射。

## 该选什么

令牌与站点域名必须配套，禁止跨国内站、国际站和 SSVIP 混用。限制到任务需要的模型、IP、速率和有效期。

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 DMXAPI · 国内站 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** DMXAPI · 国内站 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 接入地址

这把 key 是下面这些地址的 bearer token。`keykeeper run` 只设置上面的环境变量，base URL 要你自己在客户端里指。

- **OpenAI compatible**——`https://www.dmxapi.cn/v1`（China · CNY discounted）
- **Anthropic Messages**——`https://www.dmxapi.cn`（China · CNY discounted）

## 轮换与过期

创建时可设置到期时间；官方默认永久有效。以该令牌在创建页面选择的实际设置为准。 在 [www.dmxapi.cn](https://www.dmxapi.cn) 轮换或撤销。
