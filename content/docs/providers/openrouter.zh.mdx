## Agent 做什么

```bash
keykeeper providers show openrouter
keykeeper save --provider openrouter --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c openrouter -- <你的命令>
```

`--provider openrouter` 会补上凭据 ID 和字段名。这些环境变量就是 OpenRouter 自家工具读的那个，不需要任何映射。

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 OpenRouter 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** KeyKeeper 自己发送 `GET https://openrouter.ai/api/v1/key`，key 放在 `Authorization` 请求头里（reads this key's limits and usage）。Agent 收到的是「接受」「拒绝」或「联系不上」——从不是值。


## 接入地址

这把 key 是下面这些地址的 bearer token。`keykeeper run` 只设置上面的环境变量，base URL 要你自己在客户端里指。

- **OpenAI**——`https://openrouter.ai/api/v1`

## 轮换与过期

No universal expiry policy was confirmed for this credential type. Record the date shown by the provider, or leave it unknown. 在 [openrouter.ai](https://openrouter.ai/settings/keys) 轮换或撤销。
