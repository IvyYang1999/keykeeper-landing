## Agent 做什么

```bash
keykeeper providers show aws
keykeeper save --provider aws --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c aws -- <你的命令>
```

`--provider aws` 会补上凭据 ID 和字段名。这些环境变量就是 AWS 自家工具读的那个，不需要任何映射。

## 只有你能做的

<Steps>
<Step>Sign in to AWS</Step>
<Step>Use IAM Identity Center or assume a role where possible</Step>
<Step>If a key is unavoidable, create/select a dedicated IAM user</Step>
<Step>Open its Security credentials and copy the pair once</Step>
<Step>复制 key，然后在 KeyKeeper 的窗口里确认保存。</Step>
</Steps>

## 该选什么

Prefer temporary role credentials. Never create a root access key. If long-lived keys are unavoidable, attach a least-privilege policy limited by action and resource, and set rotation reminders.

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 AWS IAM · Long-lived access key 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** AWS IAM · Long-lived access key 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 轮换与过期

Long-lived IAM access keys do not expire automatically; rotate and revoke explicitly. 在 [console.aws.amazon.com](https://console.aws.amazon.com/iam/home#/users) 轮换或撤销。
