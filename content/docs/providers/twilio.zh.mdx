## Agent 做什么

```bash
keykeeper providers show twilio
keykeeper save --provider twilio --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c twilio -- <你的命令>
```

`--provider twilio` 会补上凭据 ID 和字段名。这些环境变量就是 Twilio API Key · US1 自家工具读的那个，不需要任何映射。

## 该选什么

Use a Restricted API key with only the product actions required. Prefer a subaccount boundary. Do not use the account Auth Token for an application.

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 Twilio API Key · US1 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** Twilio API Key · US1 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 轮换与过期

API keys remain valid until revoked. 在 [console.twilio.com](https://console.twilio.com/us1/account/keys-credentials/api-keys) 轮换或撤销。
