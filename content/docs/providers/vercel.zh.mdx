## Agent 做什么

```bash
keykeeper providers show vercel
keykeeper save --provider vercel --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c vercel -- <你的命令>
```

`--provider vercel` 会补上凭据 ID 和字段名。这些环境变量就是 Vercel 自家工具读的那个，不需要任何映射。

## 该选什么

范围：任务只涉及一个项目就选那个项目，否则选团队；不要选 Full Account。过期：够用的最短档（7 或 30 天），不要选不过期。

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 Vercel 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** KeyKeeper 自己发送 `GET https://api.vercel.com/v2/user`，key 放在 `Authorization` 请求头里（列出这个 token 能看到的项目）。Agent 收到的是「接受」「拒绝」或「联系不上」——从不是值。


## 轮换与过期

过期时间在创建时选（1 天到 1 年，或不过期）。泄露到公开仓库的 token 会被自动吊销。 在 [vercel.com](https://vercel.com/account/tokens) 轮换或撤销。
