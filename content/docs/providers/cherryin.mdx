## What the agent does

```bash
keykeeper providers show cherryin
keykeeper save --provider cherryin --from-clipboard --create --purpose "what this task does"
keykeeper run -c cherryin -- <your command>
```

`--provider cherryin` fills in the credential id and the field. The environment
variable is the one CherryIN's own tools read, so nothing has to be mapped.

## What to choose

日常通用调用使用 default 组的独立 token；折扣/促销组另建 token，禁止把组别不同的 key 当作可互换。为 key 设置用户可承受的额度。

<Callout type="info">
The agent is told the same thing. It opens the page for you and says what to pick; it never
logs in, passes 2FA or pays on your behalf.
</Callout>

## What KeyKeeper checks

- **Before writing:** the value must look like a CherryIN key (can be viewed again in the console). A wrong paste is refused before anything is stored, and the agent is told why — without the value.
- **After saving:** CherryIN offers no read-only endpoint KeyKeeper can use, so the first real call is the test.


## Endpoints

The key is a bearer token for these endpoints. `keykeeper run` sets only the variables above;
point your client at the base URL yourself.

- **OpenAI compatible** — `https://open.cherryin.net/v1`
- **Anthropic Messages** — `https://open.cherryin.net`
