## Agent 做什么

```bash
keykeeper providers show volcengine-ark-coding
keykeeper save --provider volcengine-ark-coding --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c volcengine-ark-coding -- <你的命令>
```

`--provider volcengine-ark-coding` 会补上凭据 ID 和字段名。这些环境变量就是 火山方舟 自家工具读的那个，不需要任何映射。

## 该选什么

Use this key only with the /api/coding/v3 base. The ordinary /api/v3 base can fall back to pay-as-you-go billing.

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 火山方舟 · Coding Plan (中国) 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** 火山方舟 · Coding Plan (中国) 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。
