## Agent 做什么

```bash
keykeeper providers show baidu-qianfan-global
keykeeper save --provider baidu-qianfan-global --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c baidu-qianfan-global -- <你的命令>
```

`--provider baidu-qianfan-global` 会补上凭据 ID 和字段名。这些环境变量就是 百度千帆 自家工具读的那个，不需要任何映射。

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 百度千帆 · 国际站 (Baidu AI Cloud Qianfan) 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** 百度千帆 · 国际站 (Baidu AI Cloud Qianfan) 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。
