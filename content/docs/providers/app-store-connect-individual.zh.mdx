## Agent 做什么

```bash
keykeeper providers show app-store-connect-individual
keykeeper save --provider app-store-connect-individual --from-file /路径/private-key.p8 --create --purpose "这个任务是做什么的"
keykeeper run -c app-store-connect-individual -- <你的命令>
```

`--provider app-store-connect-individual` 会补上凭据 ID 和字段名。这些环境变量就是 App Store Connect 自家工具读的那个，不需要任何映射。

## 该选什么

Individual keys use JWT subject user and no issuer ID. They cannot authenticate notarytool; use the team-key notary template for notarization.

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 App Store Connect · Individual API Key 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** App Store Connect · Individual API Key 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 轮换与过期

The key does not expire automatically; revoke it from App Store Connect. 在 [appstoreconnect.apple.com](https://appstoreconnect.apple.com/access/integrations/api) 轮换或撤销。
