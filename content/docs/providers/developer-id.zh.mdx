<Steps>

## 该选什么

Keep the non-exportable signing private key in the macOS Keychain and refer to the Developer ID Application identity by name. Do not copy it into a text credential.

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>


## 轮换与过期

Developer ID certificates have an Apple-issued expiration date; replace before expiry. 在 [developer.apple.com](https://developer.apple.com/account/resources/certificates/list) 轮换或撤销。
