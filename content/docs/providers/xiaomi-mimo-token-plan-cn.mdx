## What the agent does

```bash
keykeeper providers show xiaomi-mimo-token-plan-cn
keykeeper save --provider xiaomi-mimo-token-plan-cn --from-clipboard --create --purpose "what this task does"
keykeeper run -c xiaomi-mimo-token-plan-cn -- <your command>
```

`--provider xiaomi-mimo-token-plan-cn` fills in the credential id and the fields. The environment
variables are the ones Xiaomi MiMo's own tools read, so nothing has to be mapped.

## What KeyKeeper checks

- **Before writing:** the value must look like a Xiaomi MiMo · Token Plan (China) key (starts with `tp-`, shown once when created). A wrong paste is refused before anything is stored, and the agent is told why — without the value.
- **After saving:** Xiaomi MiMo · Token Plan (China) offers no read-only endpoint KeyKeeper can use, so the first real call is the test.


## Endpoints

The key is a bearer token for these endpoints. `keykeeper run` sets only the variables above;
point your client at the base URL yourself.

- **OpenAI compatible** — `https://token-plan-cn.xiaomimimo.com/v1` (中国)
- **Anthropic compatible** — `https://token-plan-cn.xiaomimimo.com/anthropic` (中国)

## Rotation and expiry

仅在所订阅 Token Plan 套餐的有效期内可用；到期后需续订。 Rotate or revoke at [platform.xiaomimimo.com](https://platform.xiaomimimo.com/).
