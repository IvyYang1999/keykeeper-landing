## 只有你能做的

<Steps>

## 该选什么

Use Installer only for signed installer packages. Application binaries require the separate Developer ID Application identity.

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>


## 轮换与过期

The Apple-issued certificate has an expiration date; record it on the credential. 在 [developer.apple.com](https://developer.apple.com/account/resources/certificates/list) 轮换或撤销。
