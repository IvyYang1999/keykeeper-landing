## What the agent does

```bash
keykeeper providers show compshare-modelverse-cn
keykeeper save --provider compshare-modelverse-cn --from-clipboard --create --purpose "what this task does"
keykeeper run -c compshare-modelverse-cn -- <your command>
```

`--provider compshare-modelverse-cn` fills in the credential id and the field. The environment
variable is the one Compshare's own tools read, so nothing has to be mapped.

## What KeyKeeper checks

- **Before writing:** the value must look like a Compshare · ModelVerse (China) key (can be viewed again in the console). A wrong paste is refused before anything is stored, and the agent is told why — without the value.
- **After saving:** Compshare · ModelVerse (China) offers no read-only endpoint KeyKeeper can use, so the first real call is the test.


## Endpoints

The key is a bearer token for these endpoints. `keykeeper run` sets only the variables above;
point your client at the base URL yourself.

- **OpenAI compatible** — `https://api.modelverse.cn/v1` (China)
- **Anthropic Messages** — `https://api.modelverse.cn` (China)
- **Gemini compatible** — `https://api.modelverse.cn` (China)
