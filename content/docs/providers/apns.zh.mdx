## Agent 做什么

```bash
keykeeper providers show apns
keykeeper save --provider apns --from-file /路径/private-key.p8 --create --purpose "这个任务是做什么的"
keykeeper run -c apns -- <你的命令>
```

`--provider apns` 会补上凭据 ID 和字段名。这些环境变量就是 Apple Push Notification service 自家工具读的那个，不需要任何映射。

## 只有你能做的

<Steps>
<Step>Sign in to the Apple Developer account</Step>
<Step>An Account Holder or Admin creates a key</Step>
<Step>Enable only Apple Push Notifications service</Step>
<Step>Download the .p8 file immediately</Step>
<Step>复制 key，然后在 KeyKeeper 的窗口里确认保存。</Step>
</Steps>

## 该选什么

Create a key with only Apple Push Notifications service enabled. Use topic restrictions where Apple offers them.

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 Apple Push Notification service 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** Apple Push Notification service 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 轮换与过期

Keys do not expire automatically; revoke and replace them from Certificates, Identifiers & Profiles. 在 [developer.apple.com](https://developer.apple.com/account/resources/authkeys/list) 轮换或撤销。
