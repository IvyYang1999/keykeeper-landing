## Agent 做什么

```bash
keykeeper providers show ccsub
keykeeper save --provider ccsub --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c ccsub -- <你的命令>
```

`--provider ccsub` 会补上凭据 ID 和字段名。这些环境变量就是 CCSub 自家工具读的那个，不需要任何映射。

## 该选什么

一个 CCSub key 可按官方配置用于 OpenAI 或 Anthropic 兼容客户端；为每个项目单独创建，避免跨工具复用。

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 CCSub 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** CCSub 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 接入地址

这把 key 是下面这些地址的 bearer token。`keykeeper run` 只设置上面的环境变量，base URL 要你自己在客户端里指。

- **OpenAI compatible**——`https://www.ccsub.net/v1`
- **Anthropic Messages**——`https://www.ccsub.net`
