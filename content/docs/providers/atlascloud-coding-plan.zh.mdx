## Agent 做什么

```bash
keykeeper providers show atlascloud-coding-plan
keykeeper save --provider atlascloud-coding-plan --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c atlascloud-coding-plan -- <你的命令>
```

`--provider atlascloud-coding-plan` 会补上凭据 ID 和字段名。这些环境变量就是 Atlas Cloud 自家工具读的那个，不需要任何映射。

## 该选什么

仅保存 Coding Plan 专用密钥；官方明确说明它与普通 Atlas Cloud API key 分离。仅用于套餐支持的 coding 工具。

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 Atlas Cloud · Coding Plan 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** Atlas Cloud · Coding Plan 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 接入地址

这把 key 是下面这些地址的 bearer token。`keykeeper run` 只设置上面的环境变量，base URL 要你自己在客户端里指。

- **OpenAI compatible**——`https://api.atlascloud.ai/v1`
- **Anthropic Messages**——`https://api.atlascloud.ai`
