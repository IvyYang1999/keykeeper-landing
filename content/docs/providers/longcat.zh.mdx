## Agent 做什么

```bash
keykeeper providers show longcat
keykeeper save --provider longcat --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c longcat -- <你的命令>
```

`--provider longcat` 会补上凭据 ID 和字段名。这些环境变量就是 LongCat 自家工具读的那个，不需要任何映射。

## 该选什么

官方快速开始未规定默认环境变量；LONGCAT_API_KEY 只是 KeyKeeper 的本地注入名，客户端必须显式读取或配置它。

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 LongCat 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** LongCat 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 接入地址

这把 key 是下面这些地址的 bearer token。`keykeeper run` 只设置上面的环境变量，base URL 要你自己在客户端里指。

- **OpenAI compatible**——`https://api.longcat.chat/openai`
- **Anthropic compatible**——`https://api.longcat.chat/anthropic`

未确认统一有效期；以创建页面显示的实际日期为准，未知时不要猜测。 在 [longcat.chat](https://longcat.chat/platform/api_keys) 轮换或撤销。
