## Agent 做什么

```bash
keykeeper providers show alibaba-bailian-token-cn
keykeeper save --provider alibaba-bailian-token-cn --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c alibaba-bailian-token-cn -- <你的命令>
```

`--provider alibaba-bailian-token-cn` 会补上凭据 ID 和字段名。这些环境变量就是 阿里云百炼 自家工具读的那个，不需要任何映射。

## 该选什么

A Token Plan key/base is isolated from both Coding Plan and pay-as-you-go. Mixing them can use the wrong quota or billing path.

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 阿里云百炼 · Token Plan (中国) 的 key（以 `sk-sp-` 开头）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** 阿里云百炼 · Token Plan (中国) 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 接入地址

这把 key 是下面这些地址的 bearer token。`keykeeper run` 只设置上面的环境变量，base URL 要你自己在客户端里指。

- **OpenAI**——`https://token-plan.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`（cn-beijing）
- **Anthropic**——`https://token-plan.cn-beijing.maas.aliyuncs.com/apps/anthropic`（cn-beijing）
