## Agent 做什么

```bash
keykeeper providers show anthropic
keykeeper save --provider anthropic --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c anthropic -- <你的命令>
```

`--provider anthropic` 会补上凭据 ID 和字段名。这个字段的环境变量就是 Anthropic 自家工具读的那个，不需要任何映射。

<Steps>

<Step>先设置好账单或额度，key 才能用</Step>
<Step>复制 key，然后在 KeyKeeper 的窗口里确认保存。</Step>

## 该选什么

在只放这个项目的工作区里创建 key；key 本身没有权限范围，工作区就是边界。

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 Anthropic 的 key（以 `sk-ant-` 开头，至少 60 个字符）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** KeyKeeper 自己发送 `GET https://api.anthropic.com/v1/models`，key 放在 `x-api-key` 请求头里（列出这把 key 能用的模型）。Agent 收到的是「接受」「拒绝」或「联系不上」——从不是值。

## 轮换与过期

key 不会过期，除非撤销。 在 [console.anthropic.com](https://console.anthropic.com/settings/keys) 轮换或撤销。
