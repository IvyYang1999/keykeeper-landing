## Agent 做什么

```bash
keykeeper providers show railway
keykeeper save --provider railway --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c railway -- <你的命令>
```

`--provider railway` 会补上凭据 ID 和字段名。这些环境变量就是 Railway 自家工具读的那个，不需要任何映射。

## 只有你能做的

<Steps>
<Step>Sign in to Railway</Step>
<Step>Open the target Project → Environment → Tokens</Step>
<Step>Create a project token for that one environment</Step>
<Step>复制 key，然后在 KeyKeeper 的窗口里确认保存。</Step>
</Steps>

## 该选什么

Use RAILWAY_TOKEN: a project token limited to one environment. Use the broader RAILWAY_API_TOKEN only for a task that genuinely spans projects or workspaces.

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 Railway 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** Railway 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 轮换与过期

No universal expiry policy was confirmed for this credential type. Record the date shown by the provider, or leave it unknown. 在 [railway.com](https://railway.com/dashboard) 轮换或撤销。
