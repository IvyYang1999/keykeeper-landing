## Agent 做什么

```bash
keykeeper providers show xiaomi-mimo-payg
keykeeper save --provider xiaomi-mimo-payg --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c xiaomi-mimo-payg -- <你的命令>
```

`--provider xiaomi-mimo-payg` 会补上凭据 ID 和字段名。这些环境变量就是 Xiaomi MiMo 自家工具读的那个，不需要任何映射。

## 只有你能做的

<Steps>
<Step>登录 Xiaomi MiMo API Open Platform</Step>
<Step>在 Console → API Keys 创建按量 key</Step>
<Step>复制 key，然后在 KeyKeeper 的窗口里确认保存。</Step>
</Steps>

## 该选什么

仅用于按量计费 API；不能用于 Token Plan endpoint。

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 Xiaomi MiMo · Pay-as-you-go 的 key（以 `sk-` 开头）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** Xiaomi MiMo · Pay-as-you-go 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 接入地址

这把 key 是下面这些地址的 bearer token。`keykeeper run` 只设置上面的环境变量，base URL 要你自己在客户端里指。

- **OpenAI compatible**——`https://api.xiaomimimo.com/v1`
- **Anthropic compatible**——`https://api.xiaomimimo.com/anthropic`
