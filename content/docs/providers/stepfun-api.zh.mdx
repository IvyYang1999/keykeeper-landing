## Agent 做什么

```bash
keykeeper providers show stepfun-api
keykeeper save --provider stepfun-api --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c stepfun-api -- <你的命令>
```

`--provider stepfun-api` 会补上凭据 ID 和字段名。这些环境变量就是 StepFun 阶跃 自家工具读的那个，不需要任何映射。

## 只有你能做的

<Steps>
<Step>登录 StepFun Open Platform</Step>
<Step>在 Account Management → Interface Keys 创建 key</Step>
<Step>复制 key，然后在 KeyKeeper 的窗口里确认保存。</Step>
</Steps>

## 该选什么

用于标准按量 API；标准 API 与 Step Plan 共用兼容协议路径，但 key、额度与计费产品不同，不要混用凭据。

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 StepFun · API 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** StepFun · API 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 接入地址

这把 key 是下面这些地址的 bearer token。`keykeeper run` 只设置上面的环境变量，base URL 要你自己在客户端里指。

- **OpenAI compatible**——`https://api.stepfun.ai/v1`
- **Anthropic compatible**——`https://api.stepfun.ai`
