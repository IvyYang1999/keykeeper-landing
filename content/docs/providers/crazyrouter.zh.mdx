## Agent 做什么

```bash
keykeeper providers show crazyrouter
keykeeper save --provider crazyrouter --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c crazyrouter -- <你的命令>
```

`--provider crazyrouter` 会补上凭据 ID 和字段名。这些环境变量就是 CrazyRouter 自家工具读的那个，不需要任何映射。

## 该选什么

为每个 IDE、CLI 或 bot 创建不同 token；限制模型、IP 和日/月预算。模型 API 必须发往 API 域名，账户管理仍使用 crazyrouter.com。

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 CrazyRouter 的 key（以 `sk-` 开头）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** CrazyRouter 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 接入地址

这把 key 是下面这些地址的 bearer token。`keykeeper run` 只设置上面的环境变量，base URL 要你自己在客户端里指。

- **OpenAI compatible**——`https://api.crazyrouter.com/v1`（International）
- **Anthropic Messages**——`https://api.crazyrouter.com`（International）
- **OpenAI compatible**——`https://cn.crazyrouter.com/v1`（East Asia）
- **Anthropic Messages**——`https://cn.crazyrouter.com`（East Asia）
