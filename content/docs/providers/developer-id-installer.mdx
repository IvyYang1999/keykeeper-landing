<Callout type="warn">
This is a signing identity that stays in the macOS Keychain. KeyKeeper stores no private key
material for it; the template only records where Apple manages it.
</Callout>

## What only you can do

<Steps>
<Step>Sign in to Apple Developer</Step>
<Step>Choose Developer ID Installer</Step>
<Step>Create it from a CSR whose private key remains on this Mac</Step>

</Steps>

## What to choose

Use Installer only for signed installer packages. Application binaries require the separate Developer ID Application identity.

<Callout type="info">
The agent is told the same thing. It opens the page for you and says what to pick; it never
logs in, passes 2FA or pays on your behalf.
</Callout>


## Rotation and expiry

The Apple-issued certificate has an expiration date; record it on the credential. Rotate or revoke at [developer.apple.com](https://developer.apple.com/account/resources/certificates/list).
