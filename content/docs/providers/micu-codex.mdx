## What the agent does

```bash
keykeeper providers show micu-codex
keykeeper save --provider micu-codex --from-clipboard --create --purpose "what this task does"
keykeeper run -c micu-codex -- <your command>
```

`--provider micu-codex` fills in the credential id and the field. The environment
variable is the one Micu API's own tools read, so nothing has to be mapped.

## What to choose

仅保存为 Codex/OpenAI Responses 协议和对应渠道分组创建的 Micu Token；不要假设它与 Claude 分组互通。

<Callout type="info">
The agent is told the same thing. It opens the page for you and says what to pick; it never
logs in, passes 2FA or pays on your behalf.
</Callout>

## What KeyKeeper checks

- **Before writing:** the value must look like a Micu API · Codex key (can be viewed again in the console). A wrong paste is refused before anything is stored, and the agent is told why — without the value.
- **After saving:** Micu API · Codex offers no read-only endpoint KeyKeeper can use, so the first real call is the test.


## Endpoints

The key is a bearer token for these endpoints. `keykeeper run` sets only the variables above;
point your client at the base URL yourself.

- **OpenAI Responses** — `https://www.micuapi.ai/v1`
