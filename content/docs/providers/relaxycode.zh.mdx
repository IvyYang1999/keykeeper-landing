## Agent 做什么

```bash
keykeeper providers show relaxycode
keykeeper save --provider relaxycode --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c relaxycode -- <你的命令>
```

`--provider relaxycode` 会补上凭据 ID 和字段名。这些环境变量就是 RelaxyCode 自家工具读的那个，不需要任何映射。

## 该选什么

按官方首页在创建时绑定所需套餐或余额。Codex 教程中的“DMXAPI token”与 RelaxyCode 域名不一致，不能据此接受其他发行方 token；仅保存 RelaxyCode 控制台实际创建的 key。

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 RelaxyCode 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** RelaxyCode 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 接入地址

这把 key 是下面这些地址的 bearer token。`keykeeper run` 只设置上面的环境变量，base URL 要你自己在客户端里指。

- **OpenAI Responses for Codex**——`https://api.relaxycode.com/v1`
