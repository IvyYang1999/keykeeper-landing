## Agent 做什么

```bash
keykeeper providers show flyio
keykeeper save --provider flyio --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c flyio -- <你的命令>
```

`--provider flyio` 会补上凭据 ID 和字段名。这些环境变量就是 Fly.io 自家工具读的那个，不需要任何映射。

## 该选什么

Prefer `fly tokens create deploy -a APP` for an app-scoped deploy token. Use an org token only when the task spans apps; do not use the short-lived all-powerful login token.

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 Fly.io 的 key（以 `FlyV1 ` 开头）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** Fly.io 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 轮换与过期

No universal expiry policy was confirmed for this credential type. Record the date shown by the provider, or leave it unknown. 在 [fly.io](https://fly.io/dashboard) 轮换或撤销。
