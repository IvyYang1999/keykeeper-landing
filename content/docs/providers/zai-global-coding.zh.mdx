## Agent 做什么

```bash
keykeeper providers show zai-global-coding
keykeeper save --provider zai-global-coding --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c zai-global-coding -- <你的命令>
```

`--provider zai-global-coding` 会补上凭据 ID 和字段名。这些环境变量就是 智谱 · Z.AI 自家工具读的那个，不需要任何映射。

## 该选什么

仅用于允许的 coding 场景：OpenAI 协议 https://api.z.ai/api/coding/paas/v4，Anthropic 协议 https://api.z.ai/api/anthropic。团队 key 与其他平台 key not interchangeable；不把团队规则推断为个人 key 有独立前缀或长度。

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 Z.AI · GLM Coding Plan (Global) 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** Z.AI · GLM Coding Plan (Global) 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 接入地址

这把 key 是下面这些地址的 bearer token。`keykeeper run` 只设置上面的环境变量，base URL 要你自己在客户端里指。

- **OpenAI Chat Completions**——`https://api.z.ai/api/coding/paas/v4`（Global）
- **Anthropic Messages**——`https://api.z.ai/api/anthropic`（Global）
- **OpenAI Responses**——`https://api.z.ai/api/v1`（Global）

## 轮换与过期

No universal expiry policy was confirmed for this credential type. Record the date shown by the provider, or leave it unknown. 在 [z.ai](https://z.ai/manage-apikey/apikey-list) 轮换或撤销。
