## Agent 做什么

```bash
keykeeper providers show npm
keykeeper save --provider npm --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c npm -- <你的命令>
```

`--provider npm` 会补上凭据 ID 和字段名。这些环境变量就是 npm 自家工具读的那个，不需要任何映射。

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 npm 的 key（以 `npm_` 开头）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** KeyKeeper 自己发送 `GET https://registry.npmjs.org/-/whoami`，key 放在 `Authorization` 请求头里（reads the npm identity for this token）。Agent 收到的是「接受」「拒绝」或「联系不上」——从不是值。


## 轮换与过期

No universal expiry policy was confirmed for this credential type. Record the date shown by the provider, or leave it unknown. 在 [www.npmjs.com](https://www.npmjs.com/settings/~/tokens) 轮换或撤销。
