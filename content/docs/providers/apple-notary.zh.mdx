## Agent 做什么

```bash
keykeeper providers show apple-notary
keykeeper save --provider apple-notary --from-clipboard --create --purpose "这个任务是做什么的"
keykeeper run -c apple-notary -- <你的命令>
```

`--provider apple-notary` 会补上凭据 ID 和字段名。这些环境变量就是 Apple Notary 自家工具读的那个，不需要任何映射。

## 该选什么

Use a dedicated app-specific password only for notarization. Keep Apple Account email and Team ID as non-secret fields in the same credential.

<Callout type="info">
Agent 被告知的是同一件事。它替你打开页面、说明该选什么；它从不替你登录、过 2FA 或付费。
</Callout>

## KeyKeeper 检查什么

- **写入前：** 值必须像一把 Apple Notary · App-Specific Password 的 key（没有形状规则）。贴错了会在存入之前被拒绝，并告诉 Agent 原因——不含值。
- **保存后：** Apple Notary · App-Specific Password 没有 KeyKeeper 可用的只读接口，第一次真实调用就是测试。


## 轮换与过期

It remains valid until revoked; changing the Apple Account password revokes all app-specific passwords. 在 [account.apple.com](https://account.apple.com/account/manage) 轮换或撤销。
