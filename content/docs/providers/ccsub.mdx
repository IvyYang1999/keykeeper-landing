## What the agent does

```bash
keykeeper providers show ccsub
keykeeper save --provider ccsub --from-clipboard --create --purpose "what this task does"
keykeeper run -c ccsub -- <your command>
```

`--provider ccsub` fills in the credential id and the field. The environment
variable is the one CCSub's own tools read, so nothing has to be mapped.

## What to choose

一个 CCSub key 可按官方配置用于 OpenAI 或 Anthropic 兼容客户端；为每个项目单独创建，避免跨工具复用。

<Callout type="info">
The agent is told the same thing. It opens the page for you and says what to pick; it never
logs in, passes 2FA or pays on your behalf.
</Callout>

## What KeyKeeper checks

- **Before writing:** the value must look like a CCSub key (can be viewed again in the console). A wrong paste is refused before anything is stored, and the agent is told why — without the value.
- **After saving:** CCSub offers no read-only endpoint KeyKeeper can use, so the first real call is the test.


## Endpoints

The key is a bearer token for these endpoints. `keykeeper run` sets only the variables above;
point your client at the base URL yourself.

- **OpenAI compatible** — `https://www.ccsub.net/v1`
- **Anthropic Messages** — `https://www.ccsub.net`
